LINUX
=====

General Commands
----------------
1. cd <directory>
   - Change current directory to <directory>.
   - Example: `cd /home/user/Documents`
2. cd ..
   - Move to the parent directory.
3. cd /
   - Go to the root directory.
4. cd ~
   - Go to the home directory.
5. pwd
   - Print the current working directory.
6. whoami
   - Show the current logged-in username.
7. sudo <command>
   - Run a command with administrative privileges.
   - Example: `sudo apt install package-name`
8. apt install <package>
   - Install a package on Debian/Ubuntu systems.
   - Example: `sudo apt install git`
9. apt update
   - Refresh the package list.
10. apt upgrade
    - Upgrade installed packages to the latest available versions.

File Management
---------------
1. touch <file>
   - Create an empty file or update a file's timestamp.
2. stat <file>
   - Display file metadata, including access and modification times.
3. ls
   - List files and directories in the current folder.
4. ls -a
   - List all files, including hidden files beginning with `.`.
5. ls -l
   - Show file details in long format (permissions, owner, size, date).
6. ls -la
   - Show all files with detailed listing.
7. cat <file>
   - Display file contents.
8. cat <source> > <destination>
   - Redirect content from one file to create or overwrite another file.
9. cp <source> <destination>
   - Copy a file or directory.
10. cp -r <source> <destination>
    - Copy a directory and its contents recursively.
11. cp -i <source> <destination>
    - Prompt before overwriting an existing file.
12. mv <source> <destination>
    - Move or rename a file or directory.
13. mv -i <source> <destination>
    - Prompt before overwriting an existing file during move.
14. mv -f <source> <destination>
    - Force move without prompts.
15. rm <file>
    - Remove a file.
12. rm -r <directory>
    - Remove a directory and its contents recursively.
13. rm -rf <path>
    - Force remove files or directories without prompts.
    - Use with extreme care: `rm -rf /path/to/folder`
14. chmod <mode> <file>
    - Change file or directory permissions.
    - Example: `chmod 755 script.sh`
15. chown <user>:<group> <file>
    - Change file or directory owner and group.
    - Example: `sudo chown user:group file.txt`
16. find <path> -name "pattern"
    - Search for files or directories matching a name pattern.
    - Example: `find . -name "*.log"`
17. grep "pattern" <file>
    - Search for text inside a file.
    - Example: `grep "error" /var/log/syslog`
18. head <file>
    - Show the first 10 lines of a file.
19. tail <file>
    - Show the last 10 lines of a file.
20. tail -f <file>
    - Follow a file as it grows (useful for log files).

Directory Management
--------------------
1. pwd
   - Print the full current working directory.
2. cd <directory>
   - Change current directory to <directory>.
   - Example: `cd /home/user/Documents`
3. cd ..
   - Move to the parent directory.
4. cd /
   - Go to the root directory.
5. cd ~
   - Go to the home directory.
6. cd -
   - Return to the previous directory.
7. ls
   - List files and directories in the current folder.
8. ls -a
   - List all files, including hidden files.
9. ls -l
   - List files with detailed metadata.
10. ls -la
    - List all files with details.
11. mkdir <directory>
    - Create a new directory.
12. mkdir -p <path>
    - Create nested directories as needed.
    - Example: `mkdir -p /tmp/project/src`
13. rmdir <directory>
    - Remove an empty directory.
14. tree [path]
    - Display a directory tree structure.
    - Example: `tree .`
15. du -sh <path>
    - Show the disk usage of a directory in human-readable form.
16. df -h
    - Show available disk space on mounted file systems.
17. pushd <directory>
    - Save current directory and switch to another.
18. popd
    - Return to the directory saved by `pushd`.
19. ln -s <target> <linkname>
    - Create a symbolic link.
    - Example: `ln -s /var/www/html ~/html-link`
20. basename <path>
    - Print the final component of a path.
21. dirname <path>
    - Print the directory portion of a path.

23. nano <file>
    - Edit a file in the Nano editor.
24. vi <file> or vim <file>
    - Edit a file in Vi/Vim.
    - Normal mode commands:
      - `dd` delete line
      - `yy` copy line
      - `p` paste
      - `u` undo
      - `/<text>` search for text
    - Insert mode entry: `i`, `a`, or `o`
    - Exit insert mode: `Esc`
    - Save: `:w`
    - Save and quit: `:wq` or `ZZ`
 

Git Basics
----------
1. git config --global user.name "Your Name"
   - Set your Git username globally.
2. git config --global user.email "you@example.com"
   - Set your Git email globally.
3. git init
   - Initialize a local Git repository.
4. git clone <url>
   - Clone a remote repository to local.
5. git status
   - Show unstaged and staged changes and branch status.
6. git add <file>
   - Stage a file for commit.
7. git add .
   - Stage all changes in the current directory.
8. git restore <file>
   - Discard local changes and restore a file from the last commit.
9. git commit -m "message"
   - Commit staged changes with a message.
10. git push
    - Push commits to the remote repository.
11. git pull
    - Fetch and merge updates from the remote repository.
12. git push --delete origin <branch>
    - Delete a remote branch from the origin remote.
    - Example: `git push --delete origin feature/login`
13. git push origin --force
    - Force push local branch changes to origin, overwriting remote history.
    - Example: `git push origin --force`
14. git branch -D <branch>
    - Force delete a local branch even if it has unmerged changes.
    - Example: `git branch -D feature/login`

Git SSH Authentication
----------------------
1. ssh-keygen -t ed25519 -C "you@example.com"
   - Generate an SSH key pair for passwordless Git authentication.
2. eval "$(ssh-agent -s)"
   - Start the SSH agent in the current shell.
3. ssh-add ~/.ssh/id_ed25519
   - Add your private SSH key to the SSH agent.
4. cat ~/.ssh/id_ed25519.pub
   - Display the public key; copy it and add it to GitHub or your Git server.
5. ssh -T git@github.com
   - Test the SSH connection to GitHub.
6. git remote set-url origin git@github.com:USERNAME/REPOSITORY.git
   - Switch a Git remote to an SSH URL for GitHub.
7. sudo apt install openssh-server
   - Install SSH server on a local Git machine if it is not already installed.
8. ssh-copy-id user@LOCAL_MACHINE_IP
   - Copy your public key to a local machine so Git can authenticate without a password.
9. mkdir -p ~/.ssh && nano ~/.ssh/config
   - Create or edit the SSH config file for easy host aliases.
10. Add the following entries to ~/.ssh/config:
    - Host github.com
      HostName github.com
      User git
      IdentityFile ~/.ssh/id_ed25519
    - Host mygitserver
      HostName LOCAL_MACHINE_IP
      User git
      IdentityFile ~/.ssh/id_ed25519
11. git remote set-url origin ssh://git@mygitserver/home/git/REPOSITORY.git
    - Use an SSH remote URL for a local Git server.
12. git push origin main
    - Push to the remote repository using SSH authentication.

Git History and Comparison
--------------------------
1. git log
   - Show the commit history of the current branch.
2. git log --oneline
   - Show a short one-line summary of each commit.
3. git log --decorate --graph --oneline --all
   - Show a visual history of commits and branches.
4. git reflog
   - Show the recent local history of HEAD movements and recovery points.
5. git diff
   - Show changes between the working directory and the last commit.
6. git diff --staged
   - Show changes that are staged but not yet committed.
7. git diff HEAD~1 HEAD
   - Compare the current commit with the previous commit.
8. git show <commit-id>
   - Display the details of a specific commit.
9. git blame <file>
   - Show who last changed each line in a file.
10. git checkout <commit-id>
    - Switch to a specific commit (use with care).
11. git revert <commit-id>
    - Create a new commit that undoes the changes from an older commit.
12. git reset --soft HEAD~1
    - Undo the last commit while keeping changes staged.
13. git reset --hard HEAD~1
    - Remove the last commit and all its changes permanently.

Notes
-----
- Hidden files begin with `.` and are not listed by default.
- Use `sudo` only when a command needs root privileges.
- In Vim, press `Esc` before entering `:w` or `:q`.
- Configure Git user name and email before making your first commit.
- SSH keys let you use Git without entering a username and password every time.
